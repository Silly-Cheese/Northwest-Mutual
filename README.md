# Northwest Mutual RP

A lightweight, fictional **medical-only insurance** portal for roleplay, built on Firebase.

## Three generations
1. **Foundation (current):** email/password accounts, customer profiles, medical plan requests, owner administration, Firestore security.
2. **Claims:** customer and provider medical claims, decisions, and simulated payouts.
3. **Finish:** reporting, printable insurance cards, mobile polish, optional Northstar Doctor-RP integration.

No Google sign-in, no mandatory email verification, and no Cloud Functions are needed.

**Important:** Owner access is granted only by a trusted Firebase Admin bootstrap script. An email address typed into an unverified public signup form never grants administrator permissions.

This project is for fictional roleplay and not real insurance, real transactions, or actual protected medical data.
